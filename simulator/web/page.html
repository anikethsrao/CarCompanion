The sketch here is the real .ino, compiled to WebAssembly with stand-ins for the Arduino core, Wire, the Seeed ADXL345 library and Adafruit SSD1306/GFX. Time is simulated, including delay() and the ~25 ms it takes to send a frame to the OLED, so animations run at the speed they would in the car.
